# 功能边界与后续计划

Accufolio 的定位是 Agent 驱动的资产配置看板：资产操作由 MCP 管理，应用提供只读总览、明细与分析。具体发布状态以 Release 和对应提交的 Actions 为准。

## 当前已实现

- 独立的资产首页与投资页面：账户现金、净资产、证券配置与收益详情，以及目标差额。
- 明确的账户类型、资金用途与原币；追加现金流水、成对转账／换汇、更正关联与版本控制。
- 按账户与标的核算证券成本和超卖，交易手续费计入成本、净收入与美元 XIRR。
- 按美东已收盘交易日重建持仓曲线，与最新行情估值分开；新浪、腾讯行情回退和真实行情时间。
- USD、CNY、HKD、EUR 展示折算；现金保留原币，历史点使用当时已发布的 ECB 快照。
- 可撤销的设备持久登录、Basic 兼容、失败限速与明确的 HTTPS 代理配置。
- 最终账户模型、业务数据 JSON 导出与 SQLite 备份；已有数据库由部署者自行适配，不提供旧账本模式或自动迁移。
- 自动历史回测、分级与退潮监控、Webhook 重试、后台心跳与失败状态、自动备份轮转和告警保留策略。

## 后续计划

| 项目 | 需要解决的问题 |
|---|---|
| 分红收益整合 | 现金分红已可记录，交易费用已计入证券；后续需将分红正确归属证券收益与总回报。 |
| 组合净值与回撤 | 当前为交易与历史收盘价重建的持仓曲线；后续需每日完整账户快照与入出金调整，计算真正的组合净值和回撤。 |
| 远程 MCP | 带认证和权限控制的远程接入，不能直接暴露当前本地 stdio 服务。 |
| 完整账户分析 | 回放现金与证券，并区分外部入出金、内部转账和汇兑效应；当前证券曲线不是完整账户净值。 |
| 定投计划 | 下次投入金额、计划日期、漏投提示；不执行交易。 |
| 持续改进认证与运维 | 当前限速为单进程状态，心跳为应用内部状态；按实际部署需求评估更完整的设备管理与外部故障检测。 |

## 明确不做

交易下单、多用户和行情分销。现金账户保留原币；非 USD 证券、负债和券商同步当前未实现。行情只用于用户自己的分析与记录，不作为数据分销服务。
