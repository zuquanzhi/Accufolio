# 功能边界与后续计划

已具备多标的只读投资看板、历史持仓曲线、配置比例与目标差额、自动历史回测、监控规则和 Webhook 告警。具体功能以 Release 说明和测试结果为准。

## 后续计划

| 项目 | 需要解决的问题 |
|---|---|
| 分红与手续费 | 账本现金流、成本、已实现收益及 XIRR 口径，并兼容旧记录。 |
| 组合净值与回撤 | 当前为交易与历史收盘价重建的持仓曲线；后续需每日完整账户快照与入出金调整，计算真正的组合净值和回撤。 |
| 远程 MCP | 带认证和权限控制的远程接入，不能直接暴露当前本地 stdio 服务。 |
| 数据导入 | 格式校验、预览、去重、备份与可撤销的导入流程。 |
| 定投计划 | 下次投入金额、计划日期、漏投提示；不执行交易。 |
| 认证加固 | 失败限速及渐进延迟，同时避免简单永久锁定成为拒绝服务入口。 |
| CNY 展示折算 | 带汇率日期与来源的只读折算，账本仍以 USD 记账。 |

## 明确不做

交易下单、多用户、多币种记账和行情分销。行情只用于用户自己的分析与记录，不作为数据分销服务。
